p.quitar {
color: red;
}
  *Declaración: selector de tipo p combinado con la clase quitar. Establece color: red.
  *Aplicación: se aplica a los <p> con class="quitar"
  *Efecto: los dos párrafos se ven con texto rojo

*.desarrollo {
font-size: 8px;
}
  *Declaración: selector universal más la clase desarrollo, equivalente a .desarrollo, establece font-size: 8px.
  *Aplicación: solo al primer párrafo, <p class="desarrollo">En este primer párrafo trataremos lo siguiente:</p>. Es el único elemento con esa clase.
  *Efecto: el texto de ese párrafo se ve en 8px.
  
.importante {
font-size: 20px;
}
  *Declaración: selector de clase simple. Establece font-size: 20px.
  *Aplicación: a los elementos con class="importante"
  *Efecto: ambos párrafos se ven con letra de 20px.
