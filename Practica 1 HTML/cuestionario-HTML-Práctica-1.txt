1. Qué es HTML, cuando fue creado, cuáles fueron las distintas versiones y cuál es la última?
HTML es un lenguaje de marcado para la elaboración de páginas web. 
Que sea de marcado significa quesignifica que no se utiliza para programar lógica, 
sino para estructurar y dar significado al contenido de una página web mediante el uso de etiquetas.
